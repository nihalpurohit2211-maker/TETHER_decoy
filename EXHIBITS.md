# EXHIBITS.md — judge-facing exhibit list

Every exhibit is generated by `tether/exhibits.py` from `results/` at M12 and
served by the dashboard at `/?exhibit=<name>`. **No number in this file, in the
dashboard, or in any slide is hand-typed.** Each exhibit declares the exact
`results/` path it reads, the unit, and its n. `docs_check.py` fails the build if
an exhibit's rendered number disagrees with `results/results.json`.

reviewed at M13a against the rules below; every caption states seed, n and unit,
the a3/a4 Phase-1 misses are called misses, the a7 leak caption prints both the
number of leaking sessions and the maximum, and the identity caption states the
key-compromise limitation.

## Caption rules (seed/n/unit enforced by `--check`; wording reviewed at M13a)

1. Each caption states seed, n and unit in the caption text itself, not only in
   a footnote.
2. A caption never says "significant" without the interval.
3. A caption for a miss says "miss" - e.g. a3/a4 residuals are captioned as
   residual misses, not as "near-perfect detection".
4. The `identity` exhibit caption must state the key-compromise limitation
   (THREAT_MODEL.md section 5.3) directly on the exhibit.

## Regeneration contract

```
python -m tether.evaluate --seed 7     # writes results/ + MANIFEST.json
python -m tether.exhibits --check      # byte-compares SVGs + captions vs results/
```

If `results/` is missing, the dashboard shows an explicit "no measured results"
state rather than placeholder numbers. That state is a feature, not a bug.
