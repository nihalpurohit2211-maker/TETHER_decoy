# EXHIBITS.md

Nine figures, generated by `tether/exhibits.py` from `results/` at M12 and
served by the dashboard at `/?exhibit=<name>`. No number in this file, on the
dashboard or on a slide is typed by hand. Each exhibit declares the `results/`
path it reads, its unit and its n. `docs_check.py` fails the build if a rendered
number disagrees with `results/results.json`.

Status legend: PLANNED (M8) -> BUILT (M12) -> VERIFIED (M13a). All nine were
reviewed at M13a against the rules below. Every caption states seed, n and unit.
The a3/a4 Phase-1 misses are called misses. The a7 leak caption prints both the
number of leaking sessions and the maximum. The identity caption states the
key-compromise limitation.

## Caption rules

`--check` enforces seed, n and unit. Wording was reviewed at M13a.

1. Each caption states seed, n and unit in the caption text itself, not only in
   a footnote.
2. A caption never says "significant" without the interval.
3. A caption for a miss says "miss". The a3/a4 residuals are captioned as
   residual misses, not as "near-perfect detection".
4. The `identity` exhibit caption states the key-compromise limitation
   (`THREAT_MODEL.md` section 5.3) directly on the exhibit.

## Regeneration

```
python -m tether.evaluate --seed 7     # writes results/ + MANIFEST.json
python -m tether.exhibits --check      # byte-compares SVGs + captions vs results/
```

If `results/` is missing, the dashboard shows an explicit "no measured results"
state instead of placeholder numbers.
